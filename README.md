# javascript-racingcar-precourse

## 애플리케이션 개요

- 사용자가 입력한 자동차 이름과 시도 횟수를 기반으로 경주를 진행하는 콘솔 게임입니다.

- 각 자동차는 0부터 9 사이의 무작위 숫자를 통해 이동 여부가 결정됩니다. (4 이상일 시 이동)

- 한 라운드가 끝날 때마다 자동차의 현재 위치를 - 로 출력합니다.

- 모든 라운드가 종료되면, 가장 많이 이동한 자동차(한 개 이상)를 최종 우승자로 출력합니다.

- Node.js 환경에서 실행되며, Jest로 기능별 단위 테스트를 수행합니다.

## 과제 체크 리스트

### 프로젝트 세팅

- [x] fork & clone

- [x] README.md에 요구 사항 리스트 정리

### 기능 목록

- [x] 주할 자동차 이름, 이동 수 입력: "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)", "시도할 횟수는 몇 회인가요?"

- [x] 이름은 5자 이하만 가능, 쉼표로 구분, 쉼표 앞 뒤 띄어쓰기 무시

- [x] 전진 조건: 0-9 무작위 값을 구했을 때 4 이상일 경우

- [x] 입력한 횟수만큼 이동 진행

- [x] 우승자 발표 (1명 이상, 여러 명일 경우 쉼표로 구분)

- [x] 유효성 검사

- [x] 에러 처리: "[ERROR]"로 시작하는 메시지와 함께 에러 발생, 애플리케이션 종료

### 프로그래밍 요구 사항

- [x] Node.js 22.19.0 버전에서 실행 가능해야 한다

- [x] 시작점은 App.js의 run()

- [x] package.json 파일은 변경할 수 없으며, 제공된 라이브러리와 스타일 라이브러리 이외의 외부 라이브러리는 사용하지 않는다

- [x] 프로그램 종료 시 process.exit()를 호출하지 않는다

- [x] 파일, 패키지 등의 이름을 바꾸거나 이동하지 않는다

- [x] indent(들여쓰기) depth 최대 2로 구현

- [x] 3항 연산자 사용 X

- [x] 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들기

- [x] Jest를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인
